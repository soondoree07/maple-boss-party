# 메이플 보스 기록

친구들끼리 메이플스토리 주간·월간 보스를 잡은 기록과 수익(결정석 + 드랍템)을 함께 남기고 보는 사이트.

- 사이트: https://maplebossparty.vercel.app (사이트 비밀번호 필요)
- Vanilla HTML + ES Module, 빌드 없음. 데이터는 Supabase(Postgres + Realtime)에 두고 모두가 같이 본다.
- `git push` 하면 Vercel 이 자동 배포한다.

## 무엇을 하나

- **유저 · 캐릭터** — 유저(잉짱, 곰범 …) 밑에 캐릭터 여러 개. "기타" 유저는 외부 인원 자리(수익 순위에서 빠짐).
- **기록 추가** — 날짜 → 참여 캐릭터(외부 인원은 "기타 − n +") → 보스 칸 여러 개(보스 · 난이도 · 그 보스 드랍템).
  보스 칸 하나가 기록(run) 하나로 저장된다. 드랍템은 분배(÷ n) 또는 독식(한 명 전액).
- **기록 카드** — 같은 주(목요일 0시 초기화) · 같은 파티 기록을 카드 한 장으로 묶는다.
- **수익 순위** — 이번 주 / 이번 달 / 전체, 유저별(캐릭터 합).
- **월별 전리품** — 메인은 이번 달, "전체 보기"로 달마다 누가 뭘 얼마에.
- **과거 기록** — 2026-09 개편 전 옛 파티(밈곰잉 · 쭈진) 기록을 달별로 정리한 읽기 전용 페이지.
- **채널 룰렛**, **라이트 / 다크 모드**.

## 돈 계산 규칙

- 결정석: 기록할 때의 가격표 값(`js/data.js`)을 기록에 같이 저장 → 가격표가 바뀌어도 지난 기록은 그대로.
  캐릭터마다 `결정석 ÷ 참여 인원 n` (n 에는 외부 인원 포함).
- 드랍템: 분배면 `가격 ÷ n` 씩, 독식이면 가져간 사람이 전액.
- 금액 표기는 억 단위, 0.1억 이상은 소수 1자리(`23.8억`), 그 아래는 2자리(`0.04억`).

## 로컬에서 보기

ES Module 이라 `file://` 로는 안 열린다. 로컬 서버로 연다.

```bash
python3 -m http.server 8765
# http://localhost:8765
```

로컬도 실제 Supabase 데이터를 그대로 읽고 쓴다(테스트 기록은 꼭 지울 것).

## 넥슨 오픈 API

- 브라우저는 넥슨을 직접 부르지 않고 서버 함수 `/api/nexon?action=...` · `/api/nexon-keys` 를 부른다. 키는 서버에만 있다.
- **Vercel 환경변수 (Production, Secret):** `NEXON_API_KEY` = 사이트 키(잉짱 계정으로 발급, 개발 단계 — 초당 5건 · 하루 1,000건), `SUPABASE_SECRET_KEY` = Supabase Secret key(RLS 를 건너뛰므로 브라우저에 두지 않는다).
- 조회(`api/nexon.js` 의 `ACTIONS`): `character`(닉네임 → 레벨 · 직업 · 월드 · 이미지, 10분 캐시) · `spec`(최종 스탯 + 장착 장비 원본, 장비 점수용, 10분) · `scheduler`(캐릭터 id → 등록 보스, 1분).
- **스케줄러는 키 주인 계정의 캐릭터만 열린다.** 그래서 유저마다 자기 넥슨 계정 키를 `nexon_keys` 테이블에 둔다(유저 관리 → 스케줄러 연결). 등록할 때 넥슨 `character/list` 로 키가 맞는지, 그 유저 캐릭터가 몇 개 열리는지 확인하고, 사이트 비밀번호를 서버에서 다시 확인한다.
- `nexon_keys` 는 RLS 켜고 정책 없음 + anon 권한 회수 → 사이트(publishable 키)로는 읽기 · 쓰기 모두 막힌다(2026-10-01 확인). 화면에는 "연결됨" 상태만 보인다.
- 기록 창: 참여 캐릭터 중 연결된 캐릭터의 스케줄러를 불러와 보스 목록을 "스케줄러 등록 보스 / 다른 보스" 로 나누고, 보스를 고르면 등록 난이도를 먼저 고른다. 연결된 캐릭터가 모두 이번 주에 잡았으면 "처치함" 표시만 한다(파티 클리어는 넥슨 반영이 늦을 수 있어 기록을 자동으로 만들지 않는다).
- 넥슨 보스 이름은 공백을 지우고 `data.js` 보스 이름과 맞춘다. 우리 목록에 없는 보스(혼테일 · 아카이럼 · 메이린 등)와 일간 보스는 버린다.
- 넥슨 로그인(Open ID)은 메이플스토리 파트너스 승인이 있어야 써서 키 방식으로 한다. 승인받으면 연결 창에 로그인 버튼을 더하면 된다.
- 넥슨 에러 함정: 없는 닉네임은 00004 로 온다. 스케줄러에서 남의 계정 캐릭터도 00003 · 00004 → "연결한 키의 계정에 이 캐릭터가 없어요" 로 바꾼다.
- 로컬(localhost)에서는 배포된 함수를 부르므로, 함수를 고쳤으면 배포한 뒤에 로컬에서 확인된다. localhost 출처만 허용한다.
- 서버 함수 주소는 비밀번호 게이트 밖이다. 조회는 누구나 부를 수 있지만(피해는 넥슨 호출 한도 정도), 키 등록 · 해제는 사이트 비밀번호가 있어야 한다.
- **유저 캐릭터 창 (`#/user/<id>`, 2026-10-01):** 수익 순위 이름 · 유저 관리 카드 이름을 누르면 들어간다. 넥슨 `profile` 조회(기본 · 스탯 · 장비 · 유니온 · 유니온 챔피언 · 링크 · 어빌리티)는 사이트 키라 모든 캐릭터가 되고, 스케줄러 카드만 본인 키가 필요하다. 별 표시 규칙: 15성 이하 한 줄 가운데 / 16~20성 아랫줄 가운데 묶음 아래 / 21성부터 아랫줄 묶음이 윗줄 사이사이.
- **출처 표기 필수:** 넥슨 이용 조건으로 서비스에 "Data based on NEXON Open API" 를 표기한다(`index.html` 의 공통 footer `.site-credit` — #app 밖이라 모든 화면 맨 아래에 늘 붙는다).
- 로드맵: 1 연결 확인(완료) → 3 스케줄러 보스 목록(완료, 2026-10-01) → 2 장비 점수 · 스펙 랭킹(보류, 결정 사항은 기획서 "장비 점수 (보류)").

## 가격표 · 드랍템 바꾸기

- **보스 반지 상자 (2026-10-01):** 드랍 목록의 리4 · 컨4 자리는 보스 · 난이도마다 다른 반지 상자 하나다(`data.js` 의 `RING_BOX_BY_DIFFICULTY`). 기록 창에서 상자를 누르면 리스트레인트 링 4 · 컨티뉴어스 링 4 · 꽝 중에서 고른다. 리4 · 컨4 는 가격을 적고, 그 외 반지는 모두 꽝 = "그 상자 이름 + 0억"으로 잠겨 기록된다. 기록 이름은 그대로 `리4` · `컨4` 라 옛 기록과 이어진다. 녹옥 상자는 4레벨이 안 나와 넣지 않는다. 새 보스는 그 표에 한 줄 더한다.
- 전리품 칸(이번 달 · 전체 보기의 달마다)에 "반지 상자 n개 · 리레4 · 컨티4 · 꽝" 집계를 보여 준다(상자 1개 = 리4 · 컨4 · 꽝(상자 이름) 줄 하나).
- 기록 창 "+ 직접 입력" 은 꺼 두었다(`loot-editor.js` 의 `ALLOW_MANUAL_LOOT`). 참여 캐릭터가 1명이면 드랍템은 무조건 그 사람 독식으로 잠기고, 파티원이 생기면 분배로 돌아간다.

- 결정석 가격, 보스 난이도, 드랍템 목록은 `js/data.js` 의 `BOSSES` 에서 고친다.
- 새 드랍템 이미지는 `png/` 에 넣고 `LOOT_IMAGE` 에 이름 → 경로를 추가한다.
- 기록 창 보스 목록: 위쪽 11개는 `data.js` `TOP_BOSS_ORDER` 순서, 나머지는 가장 비싼 난이도 결정석 순.
