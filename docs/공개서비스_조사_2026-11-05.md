# 공개 서비스(다른 사람들도 그룹 만들어 쓰기) 조사 — 2026-11-05

지금 사이트는 그대로 두고, 구조만 가져와 새 공개 사이트를 만들 수 있는지 조사했다. **결론: 넥슨 답변을 받기 전에는 새 사이트를 만들지 않는다.**

## 넥슨 오픈 API 약관 (원문 확인)
- 제5조 ① 자기 키를 타인에게 제공 · 공개 · 공유 금지, ② **타인이 발급받은 API Key 이용 금지**. 단서: 키 주인이 공개를 허용한 "일부 API"는 예외(스케줄러 포함 여부 모름).
  - 지금 사이트(사람마다 키를 서버 `nexon_keys` 에 저장 → 서버가 스케줄러 조회)는 문구상 걸린다.
- 제6조 ⑥ 승낙 없는 영리 목적 이용 금지 → 광고는 회색 지대.
- 출처 표기 "Data based on NEXON Open API" 필수, 이름 · 주소에 넥슨 상표 금지.
- 크롤링 데이터 30일 이내 갱신 의무(영문 약관은 30일 지나면 삭제).
- 호출 한도: 개발 키 초당 5 · 하루 1,000 / 서비스 키 초당 500 · 하루 2,000만(새로 발급, 서비스 URL 필요).
- 스케줄러: 보스는 잡는 순간 갱신, **최대 14일 전까지 조회 가능**.

## 넥슨 로그인 = 프렌즈 프로그램 (사용자가 로그인해 신청 화면 확인)
- "Open API를 활용한 서비스를 **운영하고 있는** 제작자라면 **누구나** 지원" — 개인 가능, 규모 조건 없음.
- 등록된 애플리케이션이 있어야 신청 가능. 적는 건 신청 동기 500자. 넥슨 팀 심사, 반려 시 사유 보고 재신청 가능.
- 현재 공식 프렌즈: 메이플지지 · 메애기 · 츄츄지지 · 메이플 히스토리.
- ⚠️ 사용자 넥슨 계정 애플리케이션 목록에 "츄츄지지 · https://chuchu.gg/" 가 등록돼 있다 — 어떻게 된 건지 아직 답 못 들음. 프렌즈 신청 전에 정리 필요(제5조 ④ 사칭 금지).

## 다른 사이트
- 메이플지지: 검색은 서비스 키, 내 정보는 넥슨 로그인. "정보 갱신" 버튼 + 마지막 업데이트 시각 + 평균 15분 지연 안내.
- 보스로그(디스코드 봇): 파티 스레드, 키 연결 선택, 자동 클리어 기록, 정산 · 미정산 추적, 목요일 요약 · 수요일 밤 알림. 무료.
- Maple Room: 보스 정산 · 길드 사이트, "처음 사용자용 이용 가이드" 메뉴, 넥슨 로그인 심사 중.

## 개인정보 (법률 자문 아님)
- 개인 · 무료여도 처리방침 공개 의무. 캐릭터명 · API 키 · 익명 ID 는 개인정보로 전제.
- 필수 기재: 목적 · 항목 · 보유기간 · 파기 · 제3자 제공 · 위탁(Supabase · Vercel) · 국외 이전 · 권리 · 안전조치 · 로컬스토리지 · 책임자 연락처 · 변경 이력.
- 꼭 필요한 정보만 쓰면 동의 없이 처리 가능 여지 큼. 맞춤 광고는 동의 + 만 14세 미만 문제.
- API 키는 암호화 저장 강하게 권고 — **지금 사이트는 원문 저장**.

## 동시 가져오기
- 지금: 사이트 전체 잠금 하나(`sync_locks`) + 전원 순서대로 조회. 공개하면 그룹끼리 막히고 시간 제한 넘음.
- 새 사이트: 그룹별 잠금 · 그룹별 쿨다운(5분) · 고정 id 로 중복 방지 · 자동 가져오기는 나눠서 대기열 · 429 면 쉬었다 재시도.

## 처음 온 사람 기준 화면 (코드 점검)
- 막힘: 입장 화면 소개 없음, 첫 설정 순서 안내 없음, 캐릭터 직접 타이핑, 키 연결 전 캐릭터 필요한데 안내 없음, "연결해야 자동 기록" 이 화면에 없음, 새 기록 버튼 없음, 분배/독식 · 기타 설명 없음, 빈 화면 문구.
- 우리 전용 하드코딩: 시드 유저 · 캐릭터, 사이트 비밀번호, 과거 기록, 고정 주소, 잉짱 서버 키, 전역 잠금, 인증 없는 API 2개.

## 사용자 판단 · 결정
- 직접 입력만 하는 사이트는 우리도 한 달 못 씀 → **자동 기록 없는 공개 사이트는 의미 없다.**
- 운영 중처럼 꾸미는 복제 사이트는 안 한다(넥슨이 호출 통계를 봄). 하려면 우리 파티가 실제로 옮겨 쓰는 방식.
- 넥슨 문의 메일: 지금 사이트가 키를 서버에 저장한다는 건 밝히지 않고, 사이트를 운영 중이라는 것만 밝힌다. 최종본은 LAST_CHAT.md.
